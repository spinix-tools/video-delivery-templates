# Delivery checklist — fictional "Lantern" launch campaign

This is a **fictional example**. The file names, sizes and durations below are the client's (made-up) delivery terms, not platform recommendations. Replace them with what your client actually agreed.

| File | Width × height | Duration | Tolerance |
|---|---|---|---|
| `Lantern_launch_16x9_15s_v03.mp4` | 1920 × 1080 | 15 s | ±0.1 s |
| `Lantern_launch_9x16_15s_v03.mp4` | 1080 × 1920 | 15 s | ±0.1 s |
| `Lantern_launch_1x1_15s_v03.mp4` | 1080 × 1080 | 15 s | ±0.1 s |

Before sending:

- [ ] Every file in the table exists, with exactly this name (version suffix included).
- [ ] No extra files (old versions, `_FINAL_final`, test renders) are in the delivery folder.
- [ ] No file appears twice.
- [ ] Width and height match.
- [ ] Duration is within the tolerance.
- [ ] Things this checklist does **not** cover were checked separately: codec, frame rate, audio, captions, colour, content.
